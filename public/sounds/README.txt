DJ Sound Effects Setup Guide
=============================

Required Files:
---------------
Place the following MP3 files in this folder:
1. airhorn.mp3 - Classic airhorn sound for DJ transitions
2. scratch.mp3 - Vinyl scratch sound effect  
3. drop.mp3 - Bass drop or impact sound

Free Sound Resources:
---------------------
- Freesound.org: https://freesound.org/
  Search: "airhorn", "dj scratch", "bass drop"
  License: Creative Commons (check attribution)

- Mixkit.co: https://mixkit.co/free-sound-effects/dj/
  No attribution required

- Zapsplat.com: https://www.zapsplat.com/
  Free with attribution

File Requirements:
------------------
- Format: MP3
- Duration: 1-3 seconds
- Sample Rate: 44.1kHz or 48kHz
- Bitrate: 128kbps minimum

Quick Setup:
------------
1. Download 3 sound files from the sources above
2. Rename them to: airhorn.mp3, scratch.mp3, drop.mp3
3. Place in /public/sounds/ directory
4. Restart the dev server if running
5. Test using the DJ Panel buttons
